# Pixel Science Studio

独立的原创科学科普动画制作项目。本阶段素材根据供应的十款造型图逐像素重绘。动画使用 01 基础款，九款科研装扮在同一套身体结构上叠加配件。参考图的文字、背景和边框没有进入素材库。

## 播放与再生成

成片为 `output/lab-test.mp4`，静帧为 `output/lab-still.png`。使用 Python 3.10 或更新版本、Pillow，以及带 libx264 的 FFmpeg。

```bash
python -m pip install -r requirements.txt
python render.py
```

只重新绘制透明角色 PNG 和场景图层时，运行 `python render.py --assets-only`。

## 角色规范

- 原生角色格为 **80 × 76 px**，透明 RGBA。默认角色面向右侧，左向使用同一图像水平翻转。
- 中性姿态使用左上原点。奶油色头壳轮廓位于 (13, 19)，尺寸 53 × 33 px。显示屏外框位于 (28, 26)，尺寸 34 × 22 px。标准金色眼睛为 3 × 7 px，两眼起点横向相差 14 px。
- 身体实验服轮廓宽 34 px，头壳与身体宽度约为 1.56 比 1。脚部左右各 13 × 6 px，站姿接地基线为第 71 像素行。耳部与头壳一起移动，嫩芽从头顶中心附近生长。坐姿通过降低身体、缩短可见腿部表现。走路与表情动画保留头壳比例。
- 画布原生分辨率为 **320 × 180 px**。导出放大四倍至 1280 × 720，采用最近邻采样，素材边缘以整数像素落点和硬边阴影保留。

## 动作规格

图集固定四列，每格 80 × 76，末行的空格不属于动作。调用 `character.sprite(action, frame, outfit, seated=False, facing=1, prop=True)` 可以输出对应帧。书桌等场景道具独立入镜时，使用 `prop=False`。模块中的 `ACTIONS` 定义图集长度和建议播放帧率。

| 动作文件 | 帧数 | 建议帧率 |
| --- | ---: | ---: |
| `idle` 待机呼吸 | 12 | 3 |
| `blink` 眨眼 | 6 | 12 |
| `walk` 行走 | 8 | 10 |
| `wave` 挥手 | 12 | 10 |
| `read` 阅读翻页 | 12 | 8 |
| `think` 思考 | 12 | 5 |
| `surprise` 惊讶 | 8 | 10 |
| `happy` 开心 | 12 | 8 |
| `microscope` 使用显微镜 | 12 | 6 |
| `sprout` 嫩芽摆动 | 12 | 6 |

## 样片时间轴

- 0–3.25 秒，进入实验室并走向书桌。
- 3.25–4 秒，停步并坐下。
- 4–6.6 秒，阅读论文，翻页两次。
- 6.6–7.45 秒，停顿思考。
- 7.45–10 秒，露出惊讶表情，弹出像素问号。

样片没有音轨，纸面用短像素线表示排版。

## 表情系统

角色实例的 `set_expression("surprised")` 设置持续表情。每次调用 `render` 可安排不同的动作和情绪帧。合成接口 `sprite_layers` 按顺序返回腿部、身体、手臂、嫩芽、头壳、面屏、眼睛、嘴巴、腮红、配饰、手持道具和前景握持层。前景握持层用于让同一只短手压住纸页。

- `assets/expressions/` 存放 16 张透明表情示例。
- `assets/expression-sheet.png` 是按表情定义顺序排列的预览图。
- `assets/layers/` 是中性姿态的独立透明图层。没有嘴形或手持道具时，相应图层可以为空。
- [角色制作 Skill](skills/pixel-science-studio/SKILL.md) 定义统一调用方式、表情键名、嫩芽模式和检查事项。

## 三段式节目模板

运行 `python render_episode.py --demo-music --previews output/program-previews` 可重建 26 秒流程样片《叶子如何利用光？》。样片使用 120 BPM 的程序生成配乐和像素中文对话，无语音旁白。

- `episodes/light_demo.py` 包含本期的独立内容与像素示意场景。
- `studio/timeline.py` 包含节目配置、动作提示和节拍时钟。
- `studio/graphics.py` 包含中文对话、论文信息卡和卷帘转场。
- `studio/renderer.py` 复用固定科研小屋、角色与表情模块，生成节目帧并输出视频。
- `output/program-previews/paper-card.png` 是独立的论文卡版式示例，可用于检查字段可读性。样片是一段流程示意，片内不展示该论文卡。

字体安装、拍点配置、外部音乐和每期制作流程见 [角色与节目制作 Skill](skills/pixel-science-studio/SKILL.md)。
